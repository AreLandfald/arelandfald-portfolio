# Assets

Legg inn bilder, video, ikoner og andre ressurser her.

Eksempler:
- HTML: `<img src="./Assets/bilde.jpg" alt="Beskrivelse">`
- CSS: `background-image: url("./Assets/bg.png");`

Tips:
- Bruk beskrivende filnavn (f.eks. `profil-portrett.jpg`).
- Optimaliser bilder for web for raskere lastetider.
